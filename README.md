# Klix - Calendários

Repositório exclusivo de instaladores e atualizações assinadas do Klix - Calendários para Windows e Android. Os outros aplicativos do estúdio têm seus próprios repositórios.

## Downloads

[Baixar a versão mais recente](https://github.com/klixestudio-lab/klix-calendarios-atualizacoes/releases/latest). Escolha o arquivo .exe para Windows ou .apk para Android.

## Canal HTTPS

Copie este endereço para Atualizações no aplicativo e salve:

```text
https://github.com/klixestudio-lab/klix-calendarios-atualizacoes/releases/latest/download/
```

Android: Verificar agora → Baixar atualização → Salvar e instalar. A instalação exige confirmação do Android. Instale sobre a versão existente para preservar os projetos.

Windows: escolha canal HTTPS em Atualizações → Versão, canal e atualizações.

As verificações automáticas dependem da rede e das permissões do sistema.

O código-fonte é mantido separadamente; este repositório distribui somente os instaladores e os manifestos de atualização.
